# 安装指南

## Go

```bash
# CLI 工具
go install github.com/goodie1972/go-cli/cmd/libra@latest

# 作为库使用
go get github.com/goodie1972/go-tokens
```

## Rust

```bash
cargo add libra-tokens
cargo add libra-leptos
```

## TypeScript

```bash
npm install @libra-design/tokens @libra-design/theme @libra-design/react
```
